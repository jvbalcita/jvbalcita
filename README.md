# Hi, I'm Jack Vincent Balcita

I build reliable enterprise, web, and desktop software for real operational work.

My core stack is **Laravel, Vue 3, Inertia.js, and Tailwind CSS**, with **Python** for automation and data workflows, and **Rust + Tauri** for lightweight cross-platform applications. I care about clear domain models, maintainable architecture, thoughtful interfaces, and systems that remain dependable as the business grows.

## What I work on

- Enterprise applications that turn complex workflows into clear, dependable tools
- Business systems for operations, finance, reporting, catalogues, payments, and scheduling
- Full-stack Laravel products with modern Vue and Inertia frontends
- Automation and integration work that removes repetitive manual processes
- Secure, testable software with practical deployment and observability

## Selected work

### [Shipped](https://github.com/jvbalcita/shipped)

A public registry for independent Laravel launches. Creators can document a release, verify its Laravel Cloud deployment, and publish a discoverable project page.

`Laravel 13` · `PHP 8.4` · `Inertia v3` · `Vue 3` · `TypeScript` · `Tailwind CSS 4` · `Pest` · `PHPStan`

### [Laravel Address](https://github.com/jvbalcita/laravel-address)

A Laravel package that provides Philippine address lookup data and APIs, including regions, provinces, cities, and barangays.

`Laravel` · `PHP` · `Package development` · `REST APIs`

## How I build

| Principle | In practice |
| --- | --- |
| Business-first | Model the real workflow before choosing the abstraction. |
| Full-stack ownership | Carry features from data and authorization through interface and delivery. |
| Quality by default | Use focused tests, static analysis, type checking, and automated CI. |
| Calm interfaces | Prefer accessible, responsive UI over decorative complexity. |
| Operational clarity | Design for deployment, recovery, auditability, and long-term maintenance. |
